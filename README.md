## Projects

| Project | What it is |
|---|---|
| [MIT NeurIPS Symmetry Flows](https://github.com/maanasgoel/MIT-NeurIPS-Symmetry-Flows) | Self-supervised learning that teaches normalizing flows the time-shift symmetry of gravitational-wave signals. NeurIPS 2023 paper. |
| [PowerMCP](https://github.com/Power-Agent/PowerMCP) | Contributed an LTspice MCP server to Harvard's Power & Agentic AI Initiative. |
| [MIT LIGO Piezo Filter Board](https://github.com/maanasgoel/MIT-LIGO-Piezo-Filter-Board) | A 12-channel analog filter and switching board for LIGO's piezo motor controls, from Altium schematics and PCB layout to firmware. |
| [Wideband Transimpedance Amplifier](https://github.com/maanasgoel/Wideband-TIA-45nm) | A 45 nm CMOS amplifier for optical receivers, designed and simulated in Cadence, that beat every target spec. |
| [MIT LIGO Parameter-Splitting Flows](https://github.com/maanasgoel/MIT-LIGO-Parameter-Splitting-Flows) | Separate normalizing flows for intrinsic and extrinsic gravitational-wave parameters, plus circular flows that trained in about 4 hours vs 11. |
| [Robo-Analyst](https://github.com/maanasgoel/Robo-Analyst) | LLM agents read SEC filings with company names hidden, and a blinded model makes each call. Finding: the LLM still recognized 97% of megacaps. |
| [SolarSprint](https://github.com/maanasgoel/SolarSprint) | A scheduler for a solar- and battery-powered AI data center, building on Prof. Lee's Curtail to Compute study. On real AI job traces, it tripled the work completed over that study's baseline. |
| [EEase](https://github.com/maanasgoel/EEase) | A local AI workbench for electrical engineers that runs LTspice simulations from plain English, solves problems from your own textbooks with citations, and writes lab reports. |
| [Reproducing HAWQ-V3](https://github.com/maanasgoel/HAWQ-V3-Reproduction) | Reproduced Hessian-based mixed-precision quantization on ResNet-18: a 41% smaller model for under 1 point of accuracy. |
| [MoKE: Mixture of Koopman Experts](https://github.com/maanasgoel/MoKE-Koopman-Experts) | Models nonlinear systems that switch between regimes, and stays stable on long predictions where standard methods diverged. |
| [Dynamic Portfolio Optimization via Forecasted Covariances](https://github.com/maanasgoel/Portfolio-Covariance-Forecasting) | An LSTM forecasts how assets move together, and its portfolio beat portfolios built on classical models (Sharpe 0.49 vs −0.07). |
| [BrakeBright](https://github.com/maanasgoel/BrakeBright) | A smart bike light that senses braking with a motion sensor, brightens automatically, and adjusts to ambient light. |
| [Beat-Frequency Metal Detector](https://github.com/maanasgoel/Beat-Frequency-Metal-Detector) | A custom PCB that turns nearby metal into an audible tone, designed, simulated, built, and tested. |
| [Analog Plotter](https://github.com/maanasgoel/Analog-Plotter) | A two-axis pen plotter with op-amp and transistor feedback control, accurate to within 1% across its range. |
| [PlateMate](https://github.com/maanasgoel/PlateMate) | Snap a photo of a meal and get its nutrition, with a MobileNetV2 classifier in a web app. |
